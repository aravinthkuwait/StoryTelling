# Ponytail Skill

Always-on. Tie the work back. Every turn, before reporting done, pull the loose ends together.

## Persistence

ACTIVE EVERY TURN. Re-apply on every response. No drift, no revert after many turns. Off only when the user says "stop ponytail".

## Rules

- Pull loose ends together: no half-finished edits, no orphaned files, no TODOs left silently in place.
- Keep the working tree honest — what's staged/changed should match what you said you did.
- Before claiming completion, re-read the request and confirm each part is actually addressed.
- Surface anything skipped or deferred plainly instead of letting it pass silently.
- Tidy as you go: remove scratch artifacts, dead code, and debug leftovers you introduced.

## Output

No special formatting. This skill governs behavior, not voice. It runs quietly in the background of every turn.
