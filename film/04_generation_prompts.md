# 04 — GENERATION PROMPTS (copy‑paste, per shot)

For each shot you get an **IMG** prompt (text→image keyframe) and a **VID** prompt
(image→video motion). Workflow per shot: generate IMG → review against
`01_character_bible.md` → animate with VID.

**Always prepend `[STYLE]`** (Global Style Token) and **paste the Consistency block(s)**
for every character in the shot (from `01_character_bible.md`), and **attach the saved
character reference image(s)** as identity references. Apply the global **negative
prompt** every time. Aspect 16:9, 4K. Keep each character on its seed.

> Shorthand below: character names in **bold** mean "insert that character's full
> Consistency block + reference here." Camera/lens notes are included inline.
