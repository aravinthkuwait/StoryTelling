## Generation order (recommended)

1. **Refs first:** mint the 7 character reference images (Step 1 in README).
2. **Drafts pass:** generate ALL shots as image keyframes on **Nano Banana Pro**, then
   quick **Wan 2.5 Fast** video drafts. Review for consistency against `01_character_bible.md`.
3. **Finals pass:** re‑render approved shots on **Kling 3.0**; render the `HERO` /
   `Veo3HERO` shots on **Veo 3 / Veo 3 Fast** only after the draft is locked.
4. Batch shots in parallel where the backend allows concurrent slots.

`S8.3` mountains/waterfalls · `S8.5` ocean sunset. These carry the spectacle and emotion;
everything else can finish on Kling 3.0.
