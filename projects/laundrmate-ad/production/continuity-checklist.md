# Laundrmate Ad — Continuity & QA Checklist

Run this checklist twice: (1) on the assembled Wan 2.5 Fast draft sequence
before spending Veo 3 credits, and (2) on the final master before export.

## Story flow (single connected narrative)

- [ ] Order is exactly: shop opening → family laundry need → app booking →
      pickup → bike travelling → shop receiving → sorting → washing → drying →
      dry cleaning → ironing → quality check → packing → delivery → happy
      customer → final call-to-action
- [ ] Every clip's last frame motion/subject leads into the next clip
      (motion continuation, matched camera direction)
- [ ] All planned match cuts land: app confirmation→bike, bag home→bag shop,
      washing drum→dryer drum, dryer door→ironing board, folded shirt→packed
      shirt, packed bag shop→delivered bag home
- [ ] No disconnected montage clips without a visible story link

## Character & prop continuity

- [ ] Same customer family in scenes 2, 4, 12 (faces, hair, clothing)
- [ ] Same delivery executive in scenes 4, 12; same branded uniform and bike
- [ ] Same branded laundry bag at pickup and shop receiving
- [ ] Same tagged school uniform, office shirt and saree traceable through
      sorting → washing → drying/dry-clean → ironing → packing → delivery
- [ ] Same shop interior layout in every shop scene
- [ ] No duplicate people in any frame; no uniform changes
- [ ] Storefront banner identical (and correctly spelled) everywhere it appears

## Lighting

- [ ] Morning light: opening + pickup (clips 01–05)
- [ ] Midday light: laundry processing (clips 06–11)
- [ ] Late afternoon / evening light: delivery + CTA (clips 13–14)

## Realism gates

- [ ] Washing: door opened by employee, sorted load, measured detergent,
      settings selected, controlled foam, clean water — no machine washing
      shoes/sarees/mats/shirts together, no bubbles filling the machine
- [ ] Drying: real drum rotation, temperature/timer checked, time-lapse for
      elapsed time — no instantly dry clothes
- [ ] Ironing: iron always human-controlled, no burning, no steam filling frame
- [ ] Dry cleaning shown separately from water washing; silk sarees never in a
      normal washer (unless care method permits)
- [ ] Shoes cleaned separately with brushes; never in a garment machine
- [ ] No floating clothes, no self-loading machines, no water/foam outside
      machines, no distorted doors/controls, no dry→wet or wet→packed garments
- [ ] Staff always purposeful — nobody standing idle
- [ ] Reactions natural, not exaggerated; no excessive slow motion
- [ ] 3D used only for: logo reveal, service labels, app interface, offer card,
      phone number, final CTA

## Editing

- [ ] Total runtime ≈ 60s; average shot length 1.5–3s
- [ ] No frozen frames, no sudden black frames (verify with notebook QC cell)
- [ ] Logo scenes brief (3D logo only ~1s at open)
- [ ] Constant frame rate and resolution across all clips after normalisation
